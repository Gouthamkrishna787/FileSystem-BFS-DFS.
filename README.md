File System Representation Using Graph (BFS and DFS)

Project Description

This project represents a file system using a graph and adjacency matrix in C programming.

Objectives

- Represent files and directories as graph nodes.
- Represent connections using an adjacency matrix.
- Implement Breadth-First Search (BFS).
- Implement Depth-First Search (DFS).
- Search for a specified file.

Technologies Used

- Programming Language: C
- Platform: GitHub
- Concept: Graph, Adjacency Matrix, BFS and DFS

Files Included

1. "file_system.c" – Main C program.
2. "input.txt" – Sample input.
3. "output.txt" – Sample output.

Expected Result

The program displays the traversal order of BFS and DFS and indicates whether the target file is found.

Conclusion

The project successfully demonstrates graph representation and graph traversal algorithms using C programming.
